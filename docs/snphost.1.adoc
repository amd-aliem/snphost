snphost(1)
==========

NAME
----
snphost - Administrative utility for AMD SEV-SNP


SYNOPSIS
--------
*snphost* [GLOBAL_OPTIONS] [_COMMAND_] [_COMMAND_ARGS_] +
*snphost* [_-h, --help_] +
*snphost* *command* *--help*


DESCRIPTION
-----------
Administrative utility for AMD SEV-SNP


GLOBAL OPTIONS
--------------
*-q, --quiet*:: Don't print anything to the console


COMMANDS
--------
*snphost show*::
	usage: snphost show [guests, identifier, tcb, vcek-url, vlek-url, hashsticks-url, version]

        Display information about the SEV-SNP platform

        snphost show guests                     Show the current number of guests
        snphost show identifier                 Show the platform identifier
        snphost show tcb                        Show the current platform and reported TCB version
        snphost show vcek-url                   Show the VCEK DER download URL
        snphost show vlek-url                   Show the VLEK DER download URL
        snphost show hashsticks-url             Show the VLEK hashsticks download URL
        snphost show version                    Show the platform's firmware version

  options:
        -h, --help      Show a help message.

*snphost export*::
	usage: snphost export [der, pem] CERT-FILE DIR-PATH

        Export a certificate chain from a kernel format file to a given directory

        ENCODING:  The format the certs will be encoded in (PEM or DER) (der, pem)
        CERT-FILE:  File where the formatted certificates are stored
        DIR-PATH:  The directory to write the certificates to

  options:
        -h, --help      Show a help message.

*snphost import*::
	usage: snphost import DIR-PATH CERT-FILE

        Import a certificate chain to a file

        DIR-PATH:  The directory where the certificates are stored
        CERT-FILE:  File where the formatted certificates will be stored

  options:
        -h, --help      Show a help message.

*snphost ok*::
	usage: snphost ok

        Probe system for SEV-SNP support

  options:
        -h, --help      Show a help message.

*snphost config*::
	usage: snphost config [set, reset]

        Modify the SNP configuration

        snphost config set                      Change the Platform Config (TCB and Mask chip) to the provided values
        snphost config reset                    Reset the SEV-SNP Config to the last comitted version

  options:
        -h, --help      Show a help message.

*snphost config set*::
	usage: snphost config set BOOTLOADER TEE SNP-FW MICROCODE MASK-CHIP [FMC]

        Change the Platform Config (TCB and Mask chip) to the provided values

        BOOTLOADER:  Bootloader version (Unsigned 8-bit Integer)
        TEE:  PSP OS version (Unsigned 8-bit Integer)
        SNP-FW:  Version of the SNP firmware (Unsigned 8-bit Integer)
        MICROCODE:  Microcode Patch level of all the cores (Unsigned 8-bit Integer)
        MASK-CHIP:  Change mask chip bit field (Unsigned 32-bit Integer) values by providing decimal representation of desired change (0-3). Bit[0]: CHIP_ID, Bit[1]: CHIP_KEY. Both are disabled by default
        [FMC]:  FMC firmware version (optional)

  options:
        -h, --help      Show a help message.

*snphost verify*::
	usage: snphost verify [certs, vlek-hashstick]

        Verify a certificate chain

        snphost verify certs                    Verify the certificate chain
        snphost verify vlek-hashstick           Verify the VLEK hashstick

  options:
        -h, --help      Show a help message.

*snphost verify certs*::
	usage: snphost verify certs DIR-PATH

        Verify the certificate chain

        DIR-PATH:  Path to directory containing certificates

  options:
        -h, --help      Show a help message.

*snphost verify vlek-hashstick*::
	usage: snphost verify vlek-hashstick HASHSTICK-FILE

        Verify the VLEK hashstick

        HASHSTICK-FILE:  Path to the VLEK hashstick file

  options:
        -h, --help      Show a help message.

*snphost fetch*::
	usage: snphost fetch [vek, ca, crl, hashsticks]

        Retrieve content from the AMD Key Distribution Server (KDS)

        snphost fetch vek                       Fetches the VCEK from the KDS
        snphost fetch ca                        Fetches the CA from the KDS
        snphost fetch crl                       Fetches the CRL from the KDS
        snphost fetch hashsticks                Fetches the VLEK hashsticks from the KDS

  options:
        -h, --help      Show a help message.

*snphost fetch vek*::
	usage: snphost fetch vek [OPTIONS] [der, pem] PATH [URL]

        Fetches the VCEK from the KDS

        ENCODING:  The format in which to encode the certificate (der, pem)
        PATH:  The path of a directory to store the encoded VEK in
        [URL]:  The URL of the VEK. If not explicitly set, the URL will be generated based on firmware data (optional)

  options:
        -e, --endorser ENDOSER  The type of the endorsement key [default: vcek]
        --client-cert CLIENT-CERT  The path of the client certificate
        --private-key PRIVATE-KEY  The path of the client private key
        -h, --help      Show a help message.

*snphost fetch ca*::
	usage: snphost fetch ca [OPTIONS] [der, pem] DIR-PATH

        Fetches the CA from the KDS

        ENCODING:  The format the certs are encoded in (der, pem)
        DIR-PATH:  The directory to write the certificates to

  options:
        -e, --endorser ENDORSER Specify which endorsement certificate chain to pull, either VCEK or VLEK [default: vcek]
        -h, --help      Show a help message.

*snphost fetch crl*::
	usage: snphost fetch crl [OPTIONS] DIR-PATH

        Fetches the CRL from the KDS

        DIR-PATH:  The directory to write the CRL to

  options:
        -e, --endorser ENDORSER Specify which endorsement CRL to pull, either VCEK or VLEK [default: vcek]
        -h, --help      Show a help message.

*snphost fetch hashsticks*::
	usage: snphost fetch hashsticks [OPTIONS] PATH CLIENT-CERT PRIVATE-KEY

        Fetches the VLEK hashsticks from the KDS

        PATH:  The path of a directory to store the encoded VEK in
        CLIENT-CERT:  The path of the client certificate
        PRIVATE-KEY:  The path of the client private key

  options:
        --hwid HWID             The hwid of the requested hash stick
        --json JSON             The path of the request file to request hashsticks for multiple machines
        -r, --result RESULT     The filename of the raw KDS response. When specified, no preprocessing will be done
        -h, --help      Show a help message.

*snphost commit*::
	usage: snphost commit

        Commit current firmware and TCB versions to PSP

  options:
        -h, --help      Show a help message.

*snphost vlek-load*::
	usage: snphost vlek-load HASHSTICK-FILE

        Load a VLEK to the system

        HASHSTICK-FILE:  File where the VLEK hashshtick is stored

  options:
        -h, --help      Show a help message.
